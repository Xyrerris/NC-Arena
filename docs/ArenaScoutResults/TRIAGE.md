# Accessibility Scanner — triage

Source: `report1.txt`–`report6.txt` and the matching screenshots, taken on a physical device on
2026-10-01 from a release build. Six scans: roster (twice), new-player form (twice), player stats
tab, and the "You" form. ROADMAP.md Phase 6 asks that every finding is triaged; this is that record.

**Status of every "fixed" row: not yet re-scanned.** The fixes are covered by the Jest suite and
`npm run verify`, which cannot see what TalkBack or the Scanner do. Install a build that contains
them and scan the same six screens again before treating the row as closed.
